# NikahFix

**Live: https://nikahfix.xsrazy.web.id**

Undangan pernikahan digital: satu halaman undangan interaktif untuk dibagikan ke para tamu.

## Fitur

- Detail acara: akad dan resepsi, waktu, dan lokasi dengan tautan peta
- Galeri foto dan hitung mundur hari acara
- Buku tamu digital: tamu bisa mengirim ucapan dan doa (tersimpan lewat backend)
- Musik latar dan amplop digital

Frontend di repo ini, backend terpisah (Express + Supabase) menangani kiriman buku tamu. Di-deploy di Vercel dan terhubung ke repo ini.
